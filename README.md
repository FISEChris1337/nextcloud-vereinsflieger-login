# Vereinsflieger Login

Log in to Nextcloud with your Vereinsflieger credentials and map club roles to Nextcloud groups.

Independent community app. **Not an official Vereinsflieger product.**

- Link existing accounts to a stable Vereinsflieger ID, manually or through an explicitly enabled email migration.
- Optionally create accounts for new members and import their first name, last name and email.
- Update verified first and last names on linked accounts after login.
- Map received roles to selected groups while preserving local memberships and admin rights.
- Protect local emergency accounts and prevent linked SSO accounts from using local account passwords.
- Use Nextcloud sessions, “Remember me” and app passwords, with Vereinsflieger and native Nextcloud two-factor authentication.
- Configure login limits and API budgets from a German or English admin interface.

Requires Nextcloud 33–35, PHP 8.3 or later and HTTPS for Vereinsflieger login.
